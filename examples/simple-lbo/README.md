# Simple LBO

This example models a basic leveraged buyout with pro forma financials, sources and uses, and IRR sensitivity analysis.

## Run

This is a standalone uv project with its own library dependencies. orcaset is pinned to `0.8.0` and resolved from the repo checkout.

Requires Python 3.14+.

```sh
cd examples/simple-lbo
uv run python main.py
```
